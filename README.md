This is my ANSC 480 Capstone precision farming project.

The goal of this project was to use the data from this website: https://homepages.inf.ed.ac.uk/rbf/PIGDATA/, to create a machine learning model that could predict when a pig would next go to the feeder from the current moment, based on its previous history of going to the feeder. 

The data provided by the website was unsatisfactory and completely erroneous in some portions, the part of my project that attempted to train on this data was therefore unsuccessful at producing meaningful results. There was too much data to sort through within the remaining time I had for this project. 
There was an attempt to automatically sort through it, but these results were also unsatisfactory.

As a proof of concept I produced some fake final ouput data that would mimic what I was looking for in the data given by the website which I would plug into the machine learning model for training. This produced a model that could make somewhat satisfactory predictions with the test data I gave it.

The code in this repository is not able to be run on any other computers besides mine without making the changes necessary to point to the correct files on the respective computer. All files addresses are absolute addresses for where I had the desired file on my computer.

ChatGPT was used when making this project to speed up development, but any AI generated code was proofread and its purpose was understood.
